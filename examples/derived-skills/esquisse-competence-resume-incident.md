# Exemple derive

Ce fichier montre a quoi pourrait ressembler un futur skill specialise, derive du catalogue texte.

## Idee de skill

- Nom potentiel: `texte-compte-rendu-incident`
- But: transformer un fil d echanges bruts en compte rendu d incident exploitable

## Perimetre possible

- entree: conversation, notes horodatees, messages disperses;
- sortie: resume, impact, chronologie, actions prises, actions a venir;
- non objectif: diagnostic technique profond ou RCA complet.

## Skills parentes mobilisables

- `texte-nettoyage-normalisation`
- `texte-synthese-structuree`
- `texte-extraction-structuree`
