# Competence: analyse-documentation

## Objectif

Analyser un contenu documentaire pour en extraire les idees essentielles et produire une synthese fiable, structuree et directement exploitable.

## Quand utiliser cette competence

- Quand il faut comprendre rapidement un article, une norme, une politique, une procedure ou une documentation de reference.
- Quand le besoin principal est d extraire l essentiel sans deformer le sens.
- Quand il faut identifier les constats, conclusions, risques, enjeux, avantages, inconvenients, limites, hypotheses, ambiguites ou points d attention.
- Quand la sortie attendue est une fiche de lecture, une note de synthese ou une analyse de contenu.

## Entrees

- Le ou les textes a analyser
- Le contexte d usage de l analyse, si connu
- Le niveau de detail attendu

## Procedure

1. Identifier le sujet exact du document et son objectif apparent.
2. Lire l ensemble du contenu avant de conclure.
3. Extraire les idees essentielles et distinguer les informations secondaires utiles.
4. Separer explicitement les faits, constats, interpretations prudentes et conclusions.
5. Relever, lorsque presents, les risques, enjeux, avantages, inconvenients, limites, hypotheses, ambiguites et points d attention.
6. Signaler ce qui est non explicite, incertain ou a valider au lieu de completer par supposition.
7. Produire une synthese structuree avec un niveau de detail adapte a l usage demande.

## Axes d analyse

- sujet principal
- objectif du document
- idees essentielles
- informations structurantes
- constats majeurs
- conclusions possibles
- risques identifies
- enjeux organisationnels, operationnels, techniques ou documentaires
- avantages et inconvenients
- limites, hypotheses et ambiguites
- points d attention
- elements a valider

Ne pas forcer un axe s il n est pas present dans le texte. Indiquer qu il n est pas explicite lorsque cela aide la lecture.

## Structure de sortie recommandee

- Titre
- Resume
- Sujet analyse
- Objectif du document
- Idees essentielles
- Constats majeurs
- Conclusions
- Risques et enjeux
- Avantages
- Inconvenients
- Limites, hypotheses et ambiguites
- Points d attention
- Elements a valider

## Validation

- Le resume est fidele au texte source.
- Les faits, constats, interpretations et conclusions sont distingues.
- Les conclusions sont soutenues par le contenu fourni.
- Les zones d incertitude sont explicites.
- La synthese est exploitable sans relire tout le document.
