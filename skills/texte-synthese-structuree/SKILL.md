# Skill: texte-synthese-structuree

## Goal

Produire une synthese courte, structuree et exploitable a partir d un contenu plus long.

## When to use

- Quand le texte source est trop long pour etre lu tel quel.
- Quand il faut ressortir les points essentiels, decisions, enjeux, risques ou actions.
- Quand la valeur attendue est la condensation et la priorisation de l information.

## Inputs

- Le texte source
- Le niveau de compression attendu
- Le format de synthese demande, si precise

## Procedure

1. Identifier la nature du document: note, article, discussion, compte rendu, documentation.
2. Extraire les points qui changent la comprehension ou l action.
3. Eliminer les details redondants, anecdotiques ou non structurants.
4. Organiser la sortie selon un schema stable: resume, points cles, risques, actions, questions ouvertes.
5. Si le texte est ambigu ou incomplet, separer clairement les faits, hypotheses et zones d incertitude.

## Validation

- La synthese couvre les idees essentielles sans recopier la source.
- Les priorites apparaissent clairement.
- Le niveau de detail correspond a la demande.
- Les absences d information critique sont signalees.
