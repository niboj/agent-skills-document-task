# Description conventions

La `description` d un `SKILL.md` sert d abord au declenchement.

## Regles

- Commencer par `Use this skill when...`
- Decrire le moment d usage, pas un concept abstrait.
- Citer la transformation principale et, si utile, le type de sortie.
- Eviter les descriptions trop larges comme "improve writing" ou "help with text".

## Bons exemples

- `Use this skill when you need to condense long notes into a structured summary with actions and risks.`
- `Use this skill when you need to extract a stable table of facts from unstructured text.`
- `Use this skill when you need to rewrite text for a formal institutional audience.`

## Mauvais exemples

- `Use this skill when working with text.`
- `Use this skill when you need better outputs.`
- `Use this skill when you need help writing anything.`
