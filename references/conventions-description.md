# Description conventions

La `description` d un `SKILL.md` sert d abord au declenchement.

## Regles

- Commencer par `Utiliser cette competence lorsqu...`
- Decrire le moment d usage, pas un concept abstrait.
- Citer la transformation principale et, si utile, le type de sortie.
- Eviter les descriptions trop larges comme "improve writing" ou "help with text".

## Bons exemples

- `Utiliser cette competence lorsqu il faut condenser de longues notes en synthese structuree avec actions et risques.`
- `Utiliser cette competence lorsqu il faut extraire un tableau stable de faits depuis un texte non structure.`
- `Utiliser cette competence lorsqu il faut reformuler un texte pour un public institutionnel formel.`

## Mauvais exemples

- `Utiliser cette competence pour travailler avec du texte.`
- `Utiliser cette competence lorsqu il faut de meilleurs resultats.`
- `Utiliser cette competence lorsqu il faut aider a rediger n importe quoi.`
