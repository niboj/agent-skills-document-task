# Index des references

Utiliser ce fichier comme point d entree pour les references d un skill quand plusieurs fichiers sont necessaires.

## Contenu recommande

- `output-template.md`: structure de sortie attendue
- `glossary.md`: termes imposes ou sensibles
- `classification-rules.md`: regles de rangement ou priorisation
- `quality-checks.md`: checklist locale

Ne creer que les fichiers dont le skill a reellement besoin.
