# Checklist de revue

- Le nom du skill est explicite et stable.
- La `description` dit clairement quand utiliser le skill.
- Le skill realise une transformation textuelle principale.
- Le `SKILL.md` reste court et procedural.
- Les references sont peu nombreuses et directement utiles.
- La sortie attendue est observable.
- Les limites et cas ambigus sont traites.
- Les cas d evaluation ressemblent a de vraies demandes.
